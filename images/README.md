# Image Guidelines

## Homepage Carousel

Carousel images should use a `3:2` aspect ratio so they fill the homepage carousel cleanly.

Recommended SVG artboard size:

```text
1200 x 800 px
```

Other valid `3:2` sizes:

```text
900 x 600 px
1500 x 1000 px
```

In Illustrator:

1. Select the Artboard Tool with `Shift + O`.
2. Set the artboard to `1200 px` wide and `800 px` high.
3. Keep important labels and content away from the edges.
4. Export/save the SVG using the artboard bounds.

The site carousel is configured as `3 / 2` and uses `object-fit: cover`, so images that are not `3:2` may be cropped.
